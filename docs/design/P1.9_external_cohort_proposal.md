# P1.9 — External-validation cohort proposal

**Date:** 2026-08-17 (supersedes the 2026-08-17 P1.9A draft; that version's
`PLASGRAPH2_BLOCKED_BY_LICENCE` finding is retained and reflected below)
**Stage:** P1.9B part E · **Status:** prospective design. Nothing imported, nothing executed.

The licence block on the plasgraph2 **repository artifacts** stands. The route below is the
**clean-room public-accession route**: public reads and references only, independently
written scripts, no derived GFA or label file copied.

---

## Design principles

- The **biological sample** is the independent unit. 436 samples, 872 graph representations.
  Eight *E. coli* samples are eight, never sixteen.
- One assembler is chosen **prospectively** for the primary graph; the second is a paired
  sensitivity arm only.
- `ambiguous` and `unlabeled` classes are retained, never merged.
- No sample is excluded for being difficult. Every exclusion is provenance, independence or
  eligibility, and every exclusion row carries `performance_based: NO`.

## Cohort 1 — Primary *E. coli* external cohort

> ### Status: `PRIMARY_ECOLI_COHORT_PENDING_INDEPENDENCE`

| Property | Value |
|---|---|
| Candidate pool | **8** plasgraph2 *E. coli* `eskapee-test` samples |
| Independent units | **8** (not 16 — two assemblers, one sample) |
| Source study | Robertson2018 |
| Public short-read accessions | 8/8 |
| Public long-read accessions | 8/8 |
| Identifier overlap with PlasEval | none |
| Identifier overlap with `CG137` | none |
| Identifier overlap with `DEV_250` | **`IDENTIFIER_INCOMPLETE`** |

**Conditions before final inclusion — all four must clear:**

1. public short- and long-read accessions verified by dereferencing each record;
2. no exact overlap with PlasEval — currently satisfied at identifier level;
3. no exact overlap with the development benchmark — **cannot be tested** until the
   owner-supplied Supplementary Table 1 arrives;
4. sequence-cluster independence under the frozen thresholds of
   `P1.9_sequence_independence_protocol.yaml`;
5. clean-room GFA and truth construction, with no unlicensed derived file used.

**Honest limitation.** Eight samples is a small cohort. It can detect a gross PPV shortfall;
it cannot resolve a few percentage points, and a cluster-level bootstrap over ≤ 8 clusters
will be wide. It is confirmatory. Cohort 2 carries the statistical weight.

Because all 8 come from Robertson2018, they are additionally **excluded from any MOB-recon
comparison** (that corpus is MOB-suite's development set). They remain valid for gplasCC,
plasmidCC and the other comparators.

## Cohort 2 — Primary cross-species external cohort

| Property | Value |
|---|---|
| Candidate pool | **254** held-out-species biological samples |
| Species | **39 — independently verified** from the sample catalogue, not taken on report |
| Partitions | `cfre-test` 50, `efer-test` 50, `bacillus-test` 34, `koxy-test` 31, `cjej-test` 30, `myco-test` 30, `sent-test` 29 |
| Public short-read accessions | **254/254** |
| Non-archival identifiers | **0** |
| Primary-cohort exclusions falling here | **0** |

Reported **separately** from *E. coli*. Metrics are never combined: 254 cross-species samples
would otherwise dominate and could mask or manufacture an *E. coli* result.

Two strata need care and are flagged now rather than discovered later:

- **Mycobacteria (30 samples, ~25 singleton species).** Cluster-level bootstrap is
  near-degenerate; report descriptively, not as a powered comparison.
- **gplasCC species-database coverage.** Its validated configuration uses a species-specific
  plasmidCC database. Which of the 39 species have one is `NOT DETERMINED`. Species without
  one are run as a separate, labelled arm or excluded with the reason recorded — never
  silently pooled with species-specific results.

## Cohort 3 — Assembler sensitivity

For every eligible biological sample, both assembler representations exist. **Primary:
Unicycler (`-u`)**, chosen prospectively because its GFA carries the `dp` normalised-depth tag
that gplasCC's coverage model consumes natively, and because P1.8B's PlasEval graphs were
Unicycler-derived, keeping graph representation comparable across our two evaluations.
**Sensitivity: SKESA (`-s`)**, analysed only after the primary result is recorded.

Reports paired per-sample agreement, whether any qualitative conclusion changes, and the
assembler-induced variance component. Assembler outputs are **never** counted as independent
isolates.

## Cohort 4 — Training / compatibility analysis

The **70** `eskapee-train` samples, including the **10 *E. coli* training samples**.

- **Excluded from primary external validation of plASgraph2** — they are its training data.
- Usable only for technical compatibility, pipeline debugging and explicitly secondary
  analyses.
- **Must never strengthen an external-validation claim.**

They are not excluded from gplasCC or plasmidCC analyses, neither of which saw this corpus;
that distinction is recorded per row rather than applied bluntly.

## Cohort 5 — Located complete-genome control set (`CG137`)

**137 complete genomes** — a real, separate collection. It **does not replace the missing
385-genome catalogue** and must never be relabelled as it.

Composition: *K. pneumoniae* 53, *S. aureus* 25, *P. aeruginosa* 24, *E. cloacae* 22,
*A. baumannii* 11, *E. hormaechei* 1, *E. asburiae* 1. 137 distinct assembly accessions,
136 distinct BioSamples, 21 BioProjects.

**Supports:** truth-construction development · controlled fragmentation · hard-negative
design · species-specific secondary validation.

**Cannot support:**

- ***E. coli* is absent.*** It cannot validate the *E. coli* gplasCC result — the very result
  P1.8B established.
- Biological and accession independence must still be established. **One overlap is already
  known:** `SAMN02700075` (*S. aureus* NRS100, `GCF_000626615.1`) is in both `CG137` and the
  plasgraph2 `eskapee-test` partition, so it is excluded from any joint analysis.
