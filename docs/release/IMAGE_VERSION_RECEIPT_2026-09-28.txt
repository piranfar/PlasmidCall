PlasmidCall release v1.1.0: image and version receipt
Date: 2026-09-28

# Purpose

This receipt backs the versions, git commits and database identities stated in
SOFTWARE_AND_DATABASE_VERSIONS.tsv, and the licence sources in
docs/release/THIRD_PARTY_LICENSE_AUDIT.tsv. It lists each read-only command run on
2026-09-28 and its output.

# How it was made

- The pinned images that ran are held by the author. Section A shows that their image IDs
  equal the image_digest column of SOFTWARE_AND_DATABASE_VERSIONS.tsv.
- Every container was started with --rm and --network none. No image was built, pulled,
  tagged or changed.
- Sections C and D are read-only HTTP GET requests to public records.
- Each output is shown as printed. Where a command would also print an unrelated warning, the
  command itself discards it (2>/dev/null), so the output shown is complete.
- The file is ASCII. Five characters outside ASCII are written as Python escapes: \u201c and
  \u201d (curly quotes) in the two geNomad licence excerpts, and \xa9 (copyright sign) in
  the SeqKit licence excerpt, all in section D.

# What it does not re-read

- The geNomad, PLASMe, PlaScope, Plasmer, Platon and HyAsP databases were mounted at run time
  and are not held with the images, so their md5 values were not recomputed here. Those md5
  values are recorded in docs/design/P1.9C4_tool_compatibility_matrix.csv. Section C shows
  that each public record named in the versions table holds files with the same md5 values.
- That design file names the Plasmer database by record 7030674. Section C shows that 7030674
  is the concept record and resolves to version record 7030675, the value in the versions
  table.
- The frozen docs/design/P1.9C4_tool_compatibility_matrix.csv (line 7) gives the Centrifuge
  inside the PlasmidEC image as 1.0.4. The package list read from that image in section B shows
  centrifuge 1.0.3. The versions table follows the image. The Centrifuge that ran for the
  PlaScope column is a different installation, in p19c4-plascope, and is 1.0.4.
- Run settings such as -s 'Escherichia coli' for PlasmidEC and --species Enterobacteriaceae
  for RFPlasmid come from scripts/evaluation/p113_tool.sh, not from this receipt.
- The licences in section D were read at the pinned tag or commit where upstream has one. For
  Plasmer no source tag matches the image, so the default branch and the LICENSE file inside
  the image were read. For BLAST+ the NCBI C++ Toolkit default branch was read, together with
  the licence fields of the conda packages in p19c2-cleanroom:1.0 and p19c4-hyasp:1.0.
