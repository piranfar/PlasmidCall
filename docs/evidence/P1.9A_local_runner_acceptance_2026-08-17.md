## Graceful stop, refusal to over-claim, and restart-safety

The strongest evidence came from the `acceptance-live` run, which was stopped mid-run:

1. `stop.ps1` wrote `STOP_REQUESTED`; the worker finished its in-flight slot and exited on
   its own. **No process was force-killed**, and nothing was deleted.
2. State after the stop: **1 of 2** receipts, `COMPLETED` absent.
3. `verify.ps1` **refused** to declare completion — `no missing receipts: FAIL — 1 missing of 2`,
   `RESULT: NOT COMPLETE … COMPLETED marker NOT created`. The gate is real, not decorative.
4. `resume.ps1` reported `already verified: 1 (will NOT be rerun)` and `slots to run: 1`,
   then relaunched detached as PID 23980.
5. `verify.ps1` then passed 12/12 and created `COMPLETED`.

That sequence demonstrates the whole restart-safety contract: completed work is never
repeated, unfinished work is resumed, and completion cannot be claimed early.

## Limitations of this test

1. **Windows and Docker restart were not simulated.** Restart-safety was demonstrated by
   process termination and resumption, which exercises the same code path (stale identity →
   resume → run only incomplete slots), but a true reboot was not performed.
2. **Container execution was not exercised.** By instruction, no gplasCC or Docker slot ran.
   `image_id` and `db_manifest` were carried as literal placeholders, so the consistency
   checks were exercised structurally rather than against real image digests.
3. **`MaxParallel` was 1.** Concurrent dispatch within a single worker is implemented as a
   sequential loop; multi-slot parallelism would need either several workers — each safe,
   since slot claims are atomic — or an extension to the dispatch loop. **This is the one
   substantive gap for a large run** and is stated rather than glossed over.
4. Shell closure was observed rather than forced: each PowerShell invocation in this
   environment is a fresh process, so the launcher exited naturally. The evidence is the
   recorded `launched_by_pid` being dead while the worker's own work completed — parent-process
   and PID evidence, as permitted.
