## 5. Consequences

1. The historical alias **“Teixeira” is preserved**. The raw file is neither renamed nor
   moved; that would require separate approval.
2. This dataset is the project's **internal development benchmark**. It is documented as
   such in `docs/MODEL_VALIDATION_STATUS.md`.
3. It **must not be described as independent validation** for any model fitted or tuned on
   it, which includes the current 12-tool ensemble and every Model 1 variant.
4. Its ground truth is binary with the equally-mapping contigs removed, so the hardest
   ambiguous cases are absent from its denominators. Reported precision and recall are
   conditioned on that exclusion.

**This does not diminish the dataset.** It is a well-constructed, peer-reviewed, hybrid-assembly-truthed
benchmark of 250 genomes across 31 species, and it remains fully valid for development,
error analysis and hard-negative characterisation. Establishing its exact identity
strengthens the provenance chain: what changes is only the *role* it can play — development,
not independent validation.
